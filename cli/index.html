Make a CV PDF from the command line

The command reads the same block the editor pastes. It writes a PDF whose text can be selected. That PDF carries document.json, so you can open it in the editor again. Nothing is uploaded.

node scripts/pdf.js catalog/software-engineer-cv.txt -o cv.pdf

What you need

  1. Node.js, and this repository on the computer.
  2. A block that starts with the document marker and ends with the end marker. The files in catalog/ are examples. The names in them are invented.
  3. Run the command from the repository folder. -o sets the PDF name. --lang nl uses Dutch headings for a Dutch block.

Examples

  • node scripts/pdf.js software-engineer-cv -o cv.pdf
  • node scripts/pdf.js software-engineer-letter -o letter.pdf
  • node scripts/pdf.js nursing-cv -o cv.pdf
  • node scripts/pdf.js nursing-letter -o letter.pdf
  • node scripts/pdf.js softwareontwikkelaar-cv --lang nl -o cv.pdf
  • node scripts/pdf.js softwareontwikkelaar-letter --lang nl -o brief.pdf
  • node scripts/pdf.js verpleegkundige-cv --lang nl -o cv.pdf
  • node scripts/pdf.js verpleegkundige-letter --lang nl -o brief.pdf

An id from that list is enough. A path to your own text file works too. The command-line PDF uses a standard typeface. The download inside the editor uses the typeface on the page. Both files can be imported.

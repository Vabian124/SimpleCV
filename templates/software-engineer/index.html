Open this CV in LibreCV

What to include

  • A role line, such as software engineer, not a list of every language.
  • One result on each project: what was slow, unclear, or missing, and what you did.
  • Languages and tools as short skills. Verbs that fit: shipped, tested, wrote, kept.
  • Leave the picture file out. The frame stays so the layout does not jump.

How to load this block

The button opens this block in the editor. You can also paste the block below yourself.

  1. Open https://librecv.org/ . For Dutch buttons, add ?lang=nl . Choose a CV or a motivation letter.
  2. On the AI step, replace the whole box with the block below. Create the document.
  3. Or, in the editor, open Use your own AI, paste the block over the box, and press Paste text.
  4. Download the PDF from the header. That PDF can be imported later because it carries document.json. Nothing is uploaded.

Command line

The same block makes a PDF from the command line. The text can be selected, and the PDF carries document.json.

node scripts/pdf.js catalog/software-engineer-cv.txt -o cv.pdf

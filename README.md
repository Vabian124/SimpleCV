# Blok-editor

Een lokale editor voor een CV of een brief. Open `index.html` in een browser, of zet deze map neer als statische site. Geen account, geen server, geen build.

Links staat het document. Rechts staan de taal, de bestandsnaam, de sjablonen, de kleuren en de blokken. Kies showcase, een lege CV of een lege brief, typ, en download een PDF. De tekst in die PDF is selecteerbaar.

Een PDF uit deze editor heeft een bijlage `document.json` met de blokken, de taal, het thema en de kleuren. Importeer die PDF en je kunt verder werken. Een PDF zonder die bijlage geeft een melding.

NL/EN wisselt de knoppen en de vaste koppen. Tekst die je zelf hebt ingevuld blijft staan.

De eigen code is CC0-1.0, zo dicht bij het publieke domein als dat hier kan. Bibliotheken houden hun eigen licentie. Zie `NOTICE`.

## English

A local editor for a CV or a letter. Open `index.html`, or host this folder as a static site. No account, no server, no build step.

The document is on the left. Language, file name, templates, colours and blocks are on the right. Pick the showcase, an empty CV or an empty letter, type, and download a PDF. The text in that PDF can be selected.

A PDF from this editor carries an attachment named `document.json`: the blocks, the language, the theme and the colours. Import that PDF to keep editing. A PDF without the attachment shows a message.

NL/EN switches the buttons and the fixed headings. Text you typed stays as it is.

The project's own code is CC0-1.0. The libraries keep their own licenses. See `NOTICE`.

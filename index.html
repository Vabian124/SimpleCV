Questions

Does LibreCV cost anything?

No. There is no account and no charge when you download the PDF. The price is zero.

Is the document uploaded?

No. The CV or letter stays in this browser. LibreCV has no account. The text is included in a feedback note only if you tick that box.

Can I write a Dutch motivation letter?

Yes. The letter and the CV are two documents. Open the Dutch page, or switch this site to NL. NL changes the buttons and the fixed headings. Text you already typed stays as it is.

Can the PDF text be selected?

Yes. The download is a PDF with real text, not a picture of the page. You can import that PDF and keep editing.

What license is the code under?

The project's own code is CC0, as close to the public domain as the law allows. The bundled libraries keep their own licenses.
